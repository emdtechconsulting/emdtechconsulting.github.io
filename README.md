# Portafolio · Javier Enriquez Morales

Web estática con HTML, CSS y JavaScript. Diseño adaptable, enlaces reales a AUREA Laravel, perfil y contacto. No requiere npm, Composer ni base de datos.

## Vista previa

Desde esta carpeta, ejecutar `python3 -m http.server 8090 --bind 127.0.0.1` y abrir http://localhost:8090. Ctrl+C detiene el servidor.

## Publicación en GitHub Pages

Crear el repositorio público `emdtechconsulting.github.io` dentro de la cuenta `emdtechconsulting`. Subir los archivos conservando assets/. En Settings > Pages, seleccionar Deploy from a branch, main, /(root), Save. La dirección prevista es https://emdtechconsulting.github.io/. No se publica hasta completar esa configuración.

## Privacidad de documentos 1.6.1
El paquete público solo incluye miniaturas pequeñas con marca de agua. Excluye PDFs originales y el catálogo con rutas a documentos completos. No incluye autenticación ni pretende impedir capturas. Acceso protegido futuro requiere almacenamiento privado y autorización del servidor; una clave JavaScript no protege archivos publicados en GitHub Pages. Al actualizar una versión previa mover assets/certificados fuera de la raíz web antes de publicar.
